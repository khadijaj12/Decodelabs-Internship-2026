# DecodeLabs AI Engineering Internship 2026

My four projects from the **DecodeLabs AI Engineering Internship (2026 Batch)**. They go from a simple rule-based system to classic machine learning, a recommendation engine and computer vision.

| # | Project | What it does | Tech |
|---|---|---|---|
| 1 | [Rule-Based Chatbot](task-1-rule-based-chatbot/) | Answers fixed questions using dictionary lookups | Python (standard library) |
| 2 | [Iris KNN Classification](task-2-iris-knn-classification/) | Classifies Iris flowers into 3 species | Scikit-learn, Pandas, Matplotlib |
| 3 | [Tech Stack Recommender](task-3-tech-stack-recommender/) | Matches your skills to job roles using TF-IDF and cosine similarity, built from scratch | Python (no ML libraries) |
| 4 | [OCR Text Recognition](task-4-ocr-text-recognition/) | Extracts text from images, keeping only high-confidence words | OpenCV, Tesseract, Matplotlib |

Each folder has its own README with how it works, how to run it, and screenshots.
